# Installing `timelink`

```shell
pip install timelink-py
```

to update

```shell
pip install -U timelink-py
```

[Docker](https://www.docker.com/) must be installed and running: the
Kleio server, which translates sources, runs in a Docker container
(started automatically when needed).

To use Timelink from notebooks, work inside a project (see
[Create a new project](../tutorial/setting_up_a_project/create_a_new_project.md))
— the template brings its own environment.
